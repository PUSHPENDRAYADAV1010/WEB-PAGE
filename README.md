# 🌐 My Personal Website

A simple and responsive personal website built using **HTML, CSS, and JavaScript**. This project showcases my profile, skills, education, and web development learning journey.

## 🚀 Live Demo

[*Add your live website link here.*](https://tomcruise10.github.io/WEB-PAGE/)

## 📌 About the Project

This is my first personal website project, created to practice the fundamentals of web development and learn how to connect multiple HTML pages using navigation links.

The website includes information about me, my education, my experience, and the programming skills I am currently learning.

## ✨ Features

* 🏠 Home page with a welcome section
* 👨‍💻 About Me page
* 🎓 Education page
* 💼 Experience page
* 🛠️ Skills showcase
* 📁 Projects section
* 📱 Responsive design for different screen sizes
* 🔗 Navigation between multiple pages
* ⚡ JavaScript alert interaction
* 🎨 Modern dark-themed user interface

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, layout, and responsive design
* **JavaScript** – Basic website interaction

## ▶️ How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/my-personal-website.git
   ```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser.

4. For a better development experience, use the **Live Server** extension in VS Code.
